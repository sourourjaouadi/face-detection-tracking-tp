## Overview

This practical project explores a complete face detection and tracking workflow on video using classical computer vision methods. It combines motion-based region proposals with Viola–Jones face detection, then analyzes extracted face crops with PCA and local visual descriptors. The final stage associates detections over time and tracks them with Kalman filters.

The code is organized into six independently runnable steps. Run the full pipeline with `all`, or run individual steps to inspect each technique.

## Pipeline

| Step | Topic | What it does | Main outputs |
| --- | --- | --- | --- |
| 1 | Motion segmentation | Builds a MOG2 foreground mask, cleans it with morphology, and finds regions of interest. | `out/s1_panel.png`, intermediate masks |
| 2 | Detection and dataset creation | Detects faces with a Haar cascade, optionally checks eyes and runs HOG person detection, then saves normalized face crops. | `out/faces/`, `out/s2_hog_montage.png` |
| 3 | PCA / eigenfaces | Fits PCA to face crops and compares low-dimensional reconstructions. | `out/s3_eigenfaces.png`, `out/s3_reconstruction.png`, `out/s3_mse_vs_k.png` |
| 4 | Harris corner analysis | Compares corner density for face, ROI, and background regions and estimates a filter threshold. | `out/s4_dens_min.txt` |
| 5 | Bag of visual words | Extracts SIFT or ORB descriptors, clusters visual words, and compares face histograms. | `out/s5_hist_face0.png`, `out/s5_neighbors.png`, `out/s5_hists.npy` |
| 6 | Face tracking | Associates detections with Hungarian matching and Kalman predictions; optionally filters with Harris density. | `out/s6_tracking.mp4`, `out/s6_log.txt` |

## Requirements

- Windows, macOS, or Linux
- Python 3.10 or newer recommended
- A video file readable by OpenCV

Python packages are listed in [`requirements.txt`](requirements.txt): OpenCV, NumPy, scikit-learn, and SciPy.

## Setup

Clone the repository and enter its directory:

```bash
git clone <your-repository-url>
cd <repository-folder>
```

Create and activate a virtual environment.

### Windows — Command Prompt

```bat
py -m venv .venv
call .venv\Scripts\activate.bat
```

### Windows — PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Use the Python executable from `.venv` when running the project. On Windows, `python` can point to a different global installation if the environment was not activated. You can always call the virtual environment directly:

```bat
.venv\Scripts\python.exe td.py --help
```

## Video input

By default, the program expects `video.mp4` in the project root. Place your own video there or pass another path with `--video`:

```bash
python td.py step2 --video path/to/input.mp4
```

The included `.gitignore` excludes `video.mp4` and generated files under `out/`, so large or personal video data and derived outputs do not get committed by accident.

## Run the project

Run all six steps in order, saving outputs without opening display windows:

```bash
python td.py all --video video.mp4 --no-show
```

Run a single step with interactive display:

```bash
python td.py step1 --video video.mp4
```

Steps 3 and 5 need the face crops generated by step 2. Step 4 analyzes regions from the video, and step 6 can use the threshold saved by step 4. For meaningful results, run the steps in sequence:

```bash
python td.py step1 --video video.mp4
python td.py step2 --video video.mp4
python td.py step3
python td.py step4 --video video.mp4
python td.py step5
python td.py step6 --video video.mp4 --harris-filter
```

The `all` command runs every step in order with the same arguments.

### Display controls

When windows are enabled:

- **Esc** or **Q**: quit the current step
- **Space**: pause or resume playback

Use `--no-show` for headless runs. Results are written to `out/` either way.

## Useful options

```text
--video PATH          Input video (default: video.mp4)
--no-show             Save outputs without display windows
--max-frames N        Process only the first N frames (0 = entire video)
--work-w N            Resize processing frames wider than N pixels (default: 640)
--full-frame          Run face detection on the whole frame
--neighbors N         Haar cascade detection threshold (default: 6)
--min-face N          Minimum detected face size (default: 80)
--stride N            Save one face crop every N frames (default: 2)
--max-faces N         Maximum crops saved (default: 300)
--desc sift|orb       Descriptor for step 5 (default: sift)
--K N                 Visual vocabulary size (default: 100)
--harris-filter       Apply Harris-density filter in step 6
--N N                 Frames to display a Kalman prediction (default: 5)
--M N                 Missed frames before deleting a track (default: 30)
```

See the complete command-line reference with:

```bash
python td.py --help
```

Example: process a short preview without display windows:

```bash
python td.py step2 --video video.mp4 --max-frames 300 --no-show
```

## Troubleshooting

### `cv2` has no attribute `HOGDescriptor`

This project uses OpenCV's standard Python API. The error can happen if `python` resolves to a different environment or an incompatible OpenCV installation. Activate `.venv` and check the interpreter and binding:

```bash
python -c "import sys, cv2; print(sys.executable); print(cv2.__version__); print(cv2.__file__); print(hasattr(cv2, 'HOGDescriptor'))"
```

On Windows, you can bypass PATH resolution by running:

```bat
.venv\Scripts\python.exe td.py step2 --video video.mp4
```

If necessary, reinstall the listed packages inside the active virtual environment:

```bash
python -m pip install --force-reinstall -r requirements.txt
```

### Too few face crops for PCA or visual words

Step 3 and step 5 need at least 10 saved face crops. Try a video with clearer, larger faces or adjust detection and sampling options, for example:

```bash
python td.py step2 --video video.mp4 --full-frame --neighbors 3 --min-face 20 --stride 1
```

### Video cannot be opened

Confirm the path is correct and that the video codec is supported by your OpenCV build. Use an absolute path if the video is outside the project directory.

## Methods

- Background subtraction: MOG2
- Binary mask cleanup: morphological opening and closing
- Face detection: Viola–Jones Haar cascades
- Optional person detection: HOG descriptor with a linear SVM
- Face appearance model: PCA / eigenfaces
- Local features: SIFT or ORB with a k-means visual vocabulary
- Tracking: Hungarian assignment and Kalman filtering
- Optional detection filter: Harris corner density
